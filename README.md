# E-Commerce Shopping Website

A responsive e-commerce shopping website built using **HTML5** and **CSS3**. This project was created as part of my **Java Full Stack Development training and assignment at SevenMentor Training and Placement**.

## 🚀 Features

* Responsive design for mobile(425px), tablet(768px), and desktop(1024px) screens
* E-commerce homepage layout
* Product categories section
* Trending products section
* Just arrived products section
* Promotional offers
* Search bar and shopping cart UI
* Newsletter subscription section
* Vendor/brand section
* Responsive footer
* Font Awesome icons integration

## 🛠️ Technologies Used

* HTML5
* CSS3
* Responsive Web Design
* Flexbox
* CSS Media Queries
* Font Awesome
